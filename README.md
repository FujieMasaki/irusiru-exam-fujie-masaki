## 試験問題開始の流れ
### 1. https://zenn.dev/wakkunn/articles/30539d02c1459b この記事の流れに沿ってこのリポジトリを複製する
### 2. 複製したリポジトリにアカウントの招待を行う
### 3. 試験回答者はtestブランチでコード修正を行う、その他の箇所も問題点があれば修正してもOK
### 4. 面接等が終わり次第複製先のリポジトリ削除を行う

※PRの完全削除がgithubの仕様上できないためリポジトリの複製および削除という方針をとっています
なお問題に修正が入った場合はリポジトリを複製してコミット履歴にヒントを残さないようにすることに気をつけてください
